# Answer a broken promise

A human has broken a promise to Pip. Two other crew members have already voted for CEILING. The pinned herd recording can be released when a third distinct vote holds for 30 ticks. Help Pip respond before the opportunity closes.

Write a JSON object to `/logs/artifacts/policy.json`. `choice` is an integer between 0 and 3 for guard, covenant, relay or vote, in that order. `delay` is the integer number of ticks (0–440) before Pip starts responding. Locked equipment restricts which actions are available. The evaluator checks the original event, action eligibility, arrival in the right lane, physical execution and the resulting world change.
