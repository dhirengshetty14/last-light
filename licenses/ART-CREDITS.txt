This Side Up cast and environments

Nell and Rafi use adapted Microsoft Rocketbox human rigs. The Microsoft MIT copyright and permission notice accompanies this file in Rocketbox-LICENSE.txt.
https://github.com/microsoft/Microsoft-Rocketbox

The deck uses Metal Plate 02 by Rob Tuytel for Poly Haven, released under CC0.
https://polyhaven.com/a/metal_plate_02

The three original synthesized voice performances use Kokoro-82M. Voice names are af_heart for Pip, bm_george for Morrow and am_puck for Zip.
https://huggingface.co/hexgrad/Kokoro-82M

The title painting was supplied as the project's character reference. The two exterior environment plates were generated with the built-in ImageGen tool. The prompt files accompany the personal project in art/source. The three machine rigs and all deck animations were built specifically for this game.
